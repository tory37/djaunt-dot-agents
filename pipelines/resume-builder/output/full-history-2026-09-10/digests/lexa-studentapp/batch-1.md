### Login, metadata, and data-integrity fixes
- **`d8fdfb61` (ASSMNT-2098)** — diagnosed a **write clobber**: `early_reader` and `spanish_early_reader` were persisted via two separate `updateStudentMetadata` calls, each spreading the same stale pre-login snapshot, so when both changed in one login (the ESL/dual-language PK-K-1 first-login case) the second call reverted the first. English lost the race every time, permanently blocking ERSS content. Fix sent **only changed keys** — removing the same defect class for adjacent fields (`esl`, `tutorInSpanish`, `saxon`, `assessmentLanguageOverride`) that could change server-side during the login's earlier awaits — coerced flags to boolean so a `null`-vs-`undefined` value couldn't drop the key, fixed the same pattern in `EarlyReaderService`, corrected the from/to telemetry, and added a regression test for the grade-1 dual-flag path.
- **`2deabf19`** — added `schoolYear` filtering across student-facing assignment queries and mutations. Fetched the assessment school year from Calendar Service on app load, made that fetch **blocking on login with retry/relogin on critical failure** (including when `schoolYear` is absent from a non-null response), added the filter to `GET_ASSIGNMENTS`/`CHECK_FOR_SCHOOL_WINDOWS` and the `addAssignment` input, and logged validation failures as `school_year_validation_failed`. Also collapsed three sequential login-path fetches (assessment calendar, school-year calendar, entitlements) into one `Promise.all` to cut login wait time.
- **`fed2a865`** — RAN dyslexia-screener images rendered broken at some districts: `RANItems` was the **only** image component that passed `imageURL` straight to `<img src>` without the `ASSET_ROOT` CDN substitution every other component applied, so it hit S3 directly where S3 is firewalled or unreliable. Hoisted the rewrite into a getter so render and the visibility-check log agree on the URL actually fetched.
- **`dc22a7e8` (ASSMNT-1946)** — non-inbox HMH launcher students were **stranded on the completion screen**: `endUserSession()` could neither close the tab (no `window.opener`) nor redirect (login origin not in the trusted allowlist), so it silently no-opped. - **`1d68c46c`, `6cad9461`, `db7bac0c`** — TTS prefetch path diverged from the speak path: prefetch didn't strip `<phoneme voice="human">` tags, so pre-recorded-audio segments were sent to TTS and cache keys never aligned. ### Layout / typography robustness

## Notable design decisions

- **Entitlement over feature flag.** Repeatedly moved gates from per-stack flags to per-district license checks, then re-added flags only as explicit fleet-wide kill switches — with the reasoning and the stakeholder who asked for it recorded in the commit.
- **Mirror sibling apps rather than reinvent.** The BTS chooser deliberately reuses the shared-services subject API the way `olp-student-experience` does instead of hand-rolling language detection.
- **Predicates should answer the question the caller is actually asking.** Renaming the Spanish PM enablement predicate to a routing predicate (`d9b50647`) after finding policy and reality diverged on legacy activities.
- **Side-effect-free mirrors for "will this fail?" checks** (`willEndUserSessionStrand`) rather than trial-and-catch.
- **Generated over hand-maintained.** Replaced drifting index-map comments with a statically-parsed generated manifest; also removed the CI test guarding it, on an explicit cost/benefit call about review attention.
- **Honest tooling copy.** Added on-page text stating the mock launcher's fixtures are guesses at item shape and skip routing/storage/scoring, because a clean-rendering page invites the reading that the feature works.
